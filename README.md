# Digital Logic Design Using Verilog

A collection of fundamental digital logic circuits designed and implemented using Verilog HDL.

## Project Objective

The objective of this repository is to implement and verify fundamental combinational digital circuits, progressing from basic logic gates to arithmetic circuits and high-speed adders.

## Designs

### Basic Logic Gates

* AND
* OR
* NOT
* XOR
* XNOR

### Arithmetic Circuits

* Half Adder
* Full Adder
* Half Subtractor
* Full Subtractor
* Ripple Carry Adder
* Carry Look-Ahead Adder

### Multiplexers

* 2:1 MUX
* 4:1 MUX
* 8:1 MUX

### Encoders and Decoders

* Decoder
* Encoder
* Priority Encoder

### Comparator

* 4-bit Magnitude Comparator

## Tools

* Verilog HDL
* Visual Studio Code
* EDA Playground
* AMD Vivado
* Git
* GitHub

## Verification

Each design will be tested using Verilog testbenches and functional simulation.
